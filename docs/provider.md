## 一、核心结论（按功能的最优选择）

| 功能 | 最优方案 | 单价 | 理由 |
|---|---|---|---|
| AI 换装（高保真） | 阿里百炼 aitryon | 0.20 元/张 | 专用试穿模型，版型/印花保持好；⚠️ **2026-10-10 下线**，官方推荐迁移至 qwen-image-2.0（同价 0.2 元） |
| AI 换装（姿势/背景还原） | 腾讯 MPS WAND-tryon flash | 2.12 元/次 | 唯一支持姿势/背景参考图的国内方案 |

### 部署方式与成本提示

1. **已托管模型**：无需部署，直接 `POST /v1/images/generations` 调用（Qwen-Image/Kolors/SD3.5/FLUX.1-schnell 等）
2. **自定义部署**：上传权重由硅基流动托管推理，按量计费（适合托管未上架模型，但无法规避许可问题）
3. **自部署省钱路线提示**：Z-Image-Turbo 等 16G 显存即可跑，但 GPU 租赁 + 运维成本需与 API 价格对比，量大才划算；且图像模型推理并发低，不适合作为多任务队列的主力

## 七、合规与支付注意事项

1. **数据出境**：国外 API（Google/OpenAI 等）需将图片上传境外服务器处理，商品图/模特图属于业务数据，跨境传输存在合规风险——与项目"国内合规"约束冲突，接入前需评估
2. **支付**：国外服务美元计费需外币卡；国内中转平台（如 apiyi 等）支持人民币按次调用，可绕开支付问题但**不能绕开数据出境**
3. **许可证**：开源试衣模型（CatVTON / IDM-VTON / OOTDiffusion 等）为 CC BY-NC-SA 非商用许可，商用项目不可用；开源文生图需注意区分（FLUX.1-schnell=Apache 2.0 可商用，FLUX.1-dev=非商用）
4. **占位价格**：MPS lite 档单价官方计费页未公开，当前 1.5 元为占位价，上线前需以控制台实际价格更新 generation-plans.ts
